# 圧力の形

村上沙織が特集記事の下書きを小池デスクの机に置いたのは、木曜の夕方だった。A4用紙七枚、見出しと本文を合わせて四千字ほど。土地の指定解除から東和地建の登記変更まで、沙織が三週間かけて積み上げた経緯を時系列で整理したものだ。小池はその場で読まず、「夜に目を通す」と言って引き出しにしまった。

翌朝、沙織が出社すると、小池はすでに自席にいた。目が合った瞬間、彼は小さく首を振った。

「社長室から話があった。昨夜のうちに。」

小池が言うには、社長室から非公式に「地域経済への影響を考慮してほしい」という要請が入ったという。具体的な文書があるわけではなく、電話一本だったらしい。それだけに始末が悪かった。記録が残らない要請は、公式の抗議よりも重くのしかかる。

「これは一企業の問題だけでなく、行政の構造的な腐敗につながっている。記者であるからには、知った事実を黙っているわけにはいかない。そこは変わりません。」沙織は言った。

「分かってる。」小池の声は低かった。「ただ、今すぐ出せる状況じゃない。もう少し証拠を固めてからにしろ。」

記事は一時保留になった。

その日の午後、沙織のスマートフォンに都市整備課の前任職員——三週間前に自宅で「もう関わりたくない」と断った男性——からショートメッセージが届いた。「先日はすみませんでした。でも、もうこれ以上は話せません。ご理解ください。」それだけだった。前回の訪問後に何らかの接触があったか、あるいは沙織が取材を続けていることが誰かの耳に入ったのか——取材を止めるよう求められたばかりか、情報源への圧力まで加わったことは、もはや疑いようがなかった。

デスクに戻ると、須田裕樹が隣の椅子を引いて座った。「村上さん、大丈夫ですか。なんか最近、顔色が悪いですよ。」

「大丈夫。」

「無理してるんじゃないですか。」須田は少し間を置いてから、「手伝えることがあれば言ってください」と付け加えた。しかし彼の声には、どこか踏み込みきれない遠慮があった。沙織は「ありがとう」と短く返し、画面に視線を戻した。

夕方、沙織は庁舎前のベンチに座り、あの夜届いた画像をもう一度開いた。差出人不明のプリペイド端末、一行のメッセージ、そして決裁書類の断片——「東和地建」という文字が鮮明に写った画像。送信者を特定する直接的な手がかりはない。

しかし、沙織は記者だった。状況を整理すれば、答えは自ずと絞られてくる。大里地区の土地審議に内部から関わっていた人物で、沙織が接触し、かつ「何かを知っている」と態度で示した人物は、今のところ藤野摂子しかいない。前任職員は沈黙を選び、議長の周辺には近づけない。あの日ロビーで、藤野はバッグの持ち手を白くなるほど握りしめていた。「分かりません」と言いながら、目は別のことを語っていた。記者である以上、確信なしに名前を出すわけにはいかない。しかし、あの画像を送れる立場にあった人間が限られる以上、藤野を送信者と見て動くことが、今できる最善の判断だった。

沙織はスマートフォンをしまい、手帳に短く書き込んだ。「F——接触継続。信頼関係の構築を優先する。」

これ以上の証拠が集まり次第、すぐに記事化に動く——その判断は揺らいでいない。ただ今は、焦って崩すよりも、静かに積み上げるほうが遠くまで届くと、沙織は自分に言い聞かせた。

アパートへの帰り道、沙織は誰にも電話しなかった。小池は組織の論理に引き戻され、須田は深みに踏み込めない。この取材が自分一人の戦いになりつつあるということを、沙織はこの夜、初めて正面から受け止めた。
