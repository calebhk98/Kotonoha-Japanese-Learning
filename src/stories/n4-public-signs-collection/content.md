日本の公共サインを読もう

日本の公共の場所には、短くて正確な日本語のサインがあります。
省略が多く、敬語・命令形・禁止表現が混在するのが特徴です。
実際によく見かける８つのサインを読んでみましょう。

📍 電車の中（優先席付近）

┌────────────────────────────┐
│　　　　優先席　　　　　　　│
│　　　　　　　　　　　　　　│
│  体の不自由な方、　　　　　│
│  妊娠中の方、　　　　　　　│
│  小さなお子様連れの方などに │
│  お譲りください　　　　　　│
└────────────────────────────┘

「お譲りください」＝「どうぞ席を渡してあげてください」
　強制ではなく、丁寧なお願いの表現です。

📍 電車の中（ドア付近）

┌────────────────────────────┐
│  携帯電話はマナーモードに   │
│  設定し、通話はご遠慮       │
│  ください。　　　　　　　　│
│　　　　　　　　　　　　　　│
│  優先席付近では電源を       │
│  お切りください。　　　　　│
└────────────────────────────┘

「ご遠慮ください」＝「しないでください」の丁寧な言い方。
「マナーモード」とは、着信音が鳴らないように設定するモードです。

📍 公園の入口

┌────────────────────────────┐
│  犬の糞は必ず持ち帰ること   │
│　　　　　　　　　　　　　　│
│  散歩マナーを守り、         │
│  みんなが使える公園に       │
│  しましょう。　　　　　　　│
└────────────────────────────┘

「〜こと」で終わる表現は、規則・義務を示す書き言葉の形です。
「〜ましょう」は一緒に行動を促す呼びかけです。

📍 飲食店の入口

┌────────────────────────────┐
│　　　　　　　　　　　　　　│
│　　　当店は全席禁煙です　　│
│　　　　　　　　　　　　　　│
│  ご理解とご協力を　　　　　│
│  お願いいたします。　　　　│
└────────────────────────────┘

「全席禁煙」＝すべての席でたばこが吸えません。
近年、日本の飲食店では屋内全面禁煙が法律で義務付けられています。

📍 コンビニのレジ付近

┌────────────────────────────┐
│  酒類・たばこをご購入の方は │
│  年齢確認が必要です。       │
│　　　　　　　　　　　　　　│
│  画面の「２０歳以上」の     │
│  ボタンをタッチしてください。│
└────────────────────────────┘

日本では酒類・たばこの購入は２０歳以上に限られています。
コンビニのレジでは年齢確認ボタンを自分でタッチする方式が一般的です。

📍 エレベーターの内側

┌────────────────────────────┐
│　　　　　　　　　　　　　　│
│　　定員：８名　　　　　　　│
│　　積載量：600 kg　　　　　│
│　　　　　　　　　　　　　　│
│  定員・積載量を超えての     │
│  ご使用はおやめください。　│
└────────────────────────────┘

「定員」＝乗れる人数の上限。「積載量」＝載せられる重さの上限。
「おやめください」＝「やめてください」の丁寧な形。

📍 図書館の入口

┌────────────────────────────┐
│  館内での飲食および　　　　│
│  携帯電話のご使用は　　　　│
│  ご遠慮ください。　　　　　│
│　　　　　　　　　　　　　　│
│  静粛にお願いいたします。　│
└────────────────────────────┘

「館内」＝建物の中。「および」＝「と・そして」の書き言葉。
「静粛に」＝静かに。硬い表現で、公共の場でよく使われます。

📍 駐車場の入口

┌────────────────────────────┐
│　　　　　　　　　　　　　　│
│　　無断駐車禁止　　　　　　│
│　　　　　　　　　　　　　　│
│  違反車両はレッカー移動     │
│  いたします。　　　　　　　│
│　　　　　　　　　　　　　　│
│  　　　駐車場管理会社　　　│
└────────────────────────────┘

「無断」＝許可なく。「レッカー移動」＝車をレッカー車で強制的に移動すること。
短い文字数で強い警告を伝えるのが駐車場サインの特徴です。

サインの言葉まとめ

| 表現　　　　　| 意味・使い方　　　　　　　|
|--------------|--------------------------|
| 〜ください   | 丁寧な依頼               |
| ご遠慮ください| 丁寧な禁止               |
| 〜禁止       | 規則としての禁止          |
| 〜こと       | 規則・義務（書き言葉）    |
| お〜ください  | より丁寧な依頼            |
