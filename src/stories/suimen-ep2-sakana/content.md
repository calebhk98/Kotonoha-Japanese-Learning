# 夜の魚

電話が鳴ったのは夜の九時過ぎだった。安西亮太（あんざい りょうた）からだと画面に出たとき、黒澤誠（くろさわ まこと）は一瞬、何か悪い知らせかと身を固めた。「高円寺、行かないか」。

机の上にはファルクナーの原稿が広げられたままだった。七時間、同じ段落と向き合い、一行も進んでいなかった。誠はその原稿を伏せ、上着を手に取った。

改札を出ると、亮太はすでに店の前に立っていた。三十代の半ば、二人でよく来たカウンターだけの店だ。

「最近どうだ」と亮太が言った。「仕事は進んでいる」と誠は答えた。どちらも嘘ではなかった。どちらも本当のことを言っていなかった。

亮太は建築の話をした。誠はうなずきながら、亮太の言葉をよそに、その顔の細部を観察していた。目の端の皺は深くなっている。しかし声の質は変わらない。三十年近く知っている人間の声が変わらないことの、奇妙な安堵。

「深海魚のドキュメンタリーを見てな」と亮太が言った。「光が届かない海域に棲んでいる。眼が退化しているのに眼がある。意味をなさない器官を持ち続ける理由が、進化の観点からはわかっていない」

誠は何も言わなかった。亮太も続けなかった。それが、この友人の話し方だった。

亮太に至っては、沈黙を埋めようとしたことが一度もない。亮太といえども、届くところと届かないところがある——二人が友人であり続けたのは、互いにそれを測り誤らなかったからだ、と誠は思ったが、声には出さなかった。

電車は空いていた。窓側の席に座ると、暗い車窓に自分の顔が映っていた。正確には、顔に似た何かが。ガラスの向こうは夜の町並みで、こちら側には蛍光灯の光がある。その二つが重なった場所に、自分の顔はある。どちらが本体でどちらが反射なのか——論理的には答えは決まっているが、視覚はそれを確信しない。

光のない場所で、眼を持っている。

玄関の引き戸を開けると、中は暗かった。靴を脱がないまま、誠は少しのあいだそこに立っていた。外でも内でもない、どちらでもない場所。やがて靴を脱ぎ、鍵を閉めた。それだけのことが、妙に長くかかった気がした。
