# 第三話：初めての飲み会で失敗した

六月、営業部の四半期飲み会があった。山本先輩は事前にルールを教えてくれた。「他の人のグラスに先に注ぐこと。乾杯まで飲まないこと。席順は入口から遠い席が新人の場所だ。あと、仕事の話はしすぎないように。でも全くしないのも変だから、まあ空気を読んで。」圭太はメモを取りたかった。

居酒屋に着くと、圭太は完璧にやろうと集中しすぎた。周りを気にして、誰のグラスが空いているか確認して、お辞儀のタイミングを計算して……気がついたら、自分のグラスにビールを注いでいた。

一瞬、場が静かになった気がした。圭太の顔が赤くなった。

藤原課長がそれを見ていた。少しの間があった。そして課長は笑った。「森くんらしいな。」

その一言で、場の空気が柔らかくなった。山本先輩も笑った。圭太も、笑うしかなかった。

それからは肩の力が抜けた。笑いながら話して、少し仕事の話もして、気づけば二時間が経っていた。帰り道、圭太はここに少しずつ居場所ができてきたような気がした。
