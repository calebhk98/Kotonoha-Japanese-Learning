## 語彙・表現メモ

| 表現 | 意味・説明 |
|------|-----------|
| 定例ミーティング | Regular / standing meeting （定例 = regularly scheduled） |
| つきましては | In light of that / Therefore — formal connective used in workplace writing |
| 承知しました | Understood / Acknowledged — polite; more formal than 了解です |
| 承知いたしました | Understood — humble form (謙譲語); more formal than 承知しました |
| 了解です | Got it — common workplace acknowledgment; slightly less formal |
| 会議室はそのままでしょうか | Will the meeting room stay the same? （そのまま = as-is, unchanged） |
| 変わりません | There is no change / It's not changing |
| 引き続き〜をお願いします | Please continue to 〜 / Please go ahead with 〜 as before |
| よろしくお願いします | Standard closing phrase expressing goodwill / please treat me well |
| 部長 | Department head / general manager — used as a title in direct address |
