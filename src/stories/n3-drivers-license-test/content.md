# 運転免許の試験

吉田恵子が試験センターに着いたのは、午前九時少し前だった。今日は二回目の路上検定だ。待合室では深呼吸をするようにしていたが、胸の緊張はなかなか消えなかった。検定員の男性は無表情で、名前を呼ぶ声だけが響いた。

走り始めると、恵子は丁寧に確認するよう意識した。ウィンカーを早めに出す。ミラーを左右順番に見る。速度を落としすぎてもいけないし、出しすぎてもいけないはずだ。交差点を三つ過ぎたころ、少し落ち着いてきた。

縦列駐車のポイントに差し掛かったとき、恵子の手が汗ばんだ。一度切り返したが、少し出すぎてしまった。後退してやり直す。今度はうまく収まった。検定員はクリップボードに何かを書いていた。

発着点に戻ると、検定員はしばらく記録を確認した。恵子はハンドルを握ったまま、結果を待った。「はい、合格です」という声が聞こえたとき、実感が少し遅れてやってきた。

待合室のベンチに座り、恵子はお母さんに電話をかけた。呼び出し音が一回鳴ると、すぐに繋がった。「受かった！」。自分でも驚くほど、声が震えていた。
