**語彙メモ**

| 表現 | 意味 |
|------|------|
| ひま | free / not busy |
| いいじゃん | that sounds good / isn't that great |

| 全然オッケー | totally okay |
| 〜かも | maybe / might |
| 了解 | understood / roger that |
| 着替える | to change clothes |
| ずらす | to shift / move (a schedule) |
| ゆっくり来てね | take your time coming |
