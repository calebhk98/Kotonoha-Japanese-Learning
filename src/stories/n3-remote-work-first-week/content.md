# テレワーク初週間

月曜日、小川みさきはキッチンのテーブルに自分のノートパソコンを置いた。在宅勤務というのは、ちゃんとした机がなくてもできるものだと思っていた。でも猫のムギが何度もキーボードの上を歩いてしまい、送信するつもりのないメッセージを三回も飛ばしてしまった。

火曜日、初めてのオンライン会議があった。カメラをオンにした瞬間、背景に洗濯物が映っているのに気づいた。慌ててぼかし機能を使うようにしたが、少し遅かった気がする。

水曜日の午後三時、みさきはふと気づいた。朝からずっとパジャマのままだ。通勤がないと、着替えるきっかけがない。これではいけないと思い、翌日からは出社するときと同じ時間に起きることにした。

木曜日、音楽を聴きながら作業していたら、チャットの重要なメッセージを見逃してしまった。上司からの確認依頼だった。集中力を保つのが、思ったより難しい。

金曜日の夕方、みさきはチームのグループチャットに短いメッセージを送った。「今週いろいろ失敗しましたが、少しずつ慣れてきました。オフィスのコーヒーメーカーだけが、やっぱり恋しいです」
