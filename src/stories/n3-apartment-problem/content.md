# アパートのトラブル

大雨が降った翌朝、井上りなは寝室の天井に茶色いしみができているのに気づいた。昨日はなかったはずだ。時間が経つにつれて、しみは少しずつ広がっているように見えた。りなはスマートフォンで写真を何枚も撮っておいた。

すぐに管理会社に電話した。担当者は丁寧な口調で「ご連絡ありがとうございます。確認して折り返しご連絡いたします」と言った。でも二日経っても、連絡は来なかった。

三日目の午前中、りなはもう一度電話した。今度は少しはっきりと伝えた。「天井の水漏れがひどくなっています。早めに対応していただけますか」。その日の夕方、ようやく業者が来ることになった。

業者によると、上の階のバスルームからの水漏れだということがわかった。修理のために上の住人に立ち会ってもらう必要があり、りなが直接インターホンを押すことになった。顔も知らない隣人に話しかけるのは、少し気まずかった。

修理は翌週に完了した。パッチを当てられた天井を見上げながら、りなはその夜、日記に書いた。「一人暮らしって、思っていたより大変なことが多い。でも、なんとか自分で対処できた」
