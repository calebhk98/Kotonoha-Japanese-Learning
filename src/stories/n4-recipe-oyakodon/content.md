# 親子丼のレシピ

ふんわり卵と鶏肉が絶妙な、定番の親子丼です。

---

## 材料（2人分）

| 材料 | 分量 |
|------|------|
| 鶏もも肉 | 200g（一口大に切る） |
| 卵 | 3個 |
| 玉ねぎ | 1/2個（薄切り） |
| だし | 150ml |
| 醤油 | 大さじ2 |
| みりん | 大さじ2 |
| 砂糖 | 小さじ1 |
| ご飯 | 2膳分 |

---

## 作り方

1. だし・醤油・みりん・砂糖を小鍋に入れ、中火で温めます。

2. 玉ねぎを加えて、しんなりするまで3〜4分ほど炒めます。

3. 鶏もも肉を加え、色が変わるまで火を通します。

4. 溶いた卵を全体に回しかけ、ふたをして弱火で1〜2分蒸らします。卵が半熟になったら火を止めます。

5. 丼にご飯を盛り、4をご飯の上にそっとのせます。

6. お好みで三つ葉や刻みのりをトッピングしてどうぞ。

---

**ポイント：** 卵は半熟で仕上げるのがおいしさの秘訣です。火を止めるタイミングが早めでも、余熱で丁度よく仕上がります。
