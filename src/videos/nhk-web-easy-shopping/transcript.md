お買い物の日本語を勉強しましょう。

## お店に入ったとき

店員さんはよく「いらっしゃいませ」と言います。
これは「ようこそ」という意味のあいさつです。
返事をしなくてもだいじょうぶです。

お店の中を見ているとき、店員さんが「何かお探しですか。」と聞くことがあります。
「ちょっと見ているだけです。」と言えば、一人でゆっくり見られます。

## サイズと色を聞く

洋服屋さんでよく使う言葉：

「このシャツのMサイズはありますか。」
「もう少し大きいサイズはありますか。」
「もう少し小さいものはありますか。」
「同じデザインで、青いのはありますか。」
「〜はございますか。」は「〜はありますか。」の丁寧な言い方です。

試着室を使うとき：
「試着してもいいですか。」
「試着室はどこですか。」
「着てみていいですか。」

## 値段を確認する

「これはいくらですか。」
「〜円ですか。少し高いですね。」
「セールはありますか。」
「値引きはできますか。」

スーパーでよく使う言葉：
「〜はどこにありますか。」
「〜売り場はどこですか。」
「賞味期限はいつまでですか。」

## お会計

「お会計をお願いします。」
「お会計はこちらへどうぞ。」

支払い方法：
「現金で払います。」
「カードで払えますか。」
「Suicaは使えますか。」
「PayPayは使えますか。」

「袋はいりますか。」と聞かれたら：
「はい、お願いします。」
「いいえ、けっこうです。」（いりません）
「エコバッグがあります。」

おつりをもらうとき：
「〜円のお返しです。」
「レシートをください。」

## よく使う表現まとめ

| 場面 | 表現 |
|---|---|
| 探しているとき | 「〜はありますか。／〜はございますか。」 |
| 見ているだけ | 「ちょっと見ているだけです。」 |
| 試着 | 「試着してもいいですか。」 |
| 値段 | 「これはいくらですか。」 |
| 支払い | 「カードで払えますか。」 |
| 袋 | 「袋はけっこうです。」 |

## 練習してみよう

A：「いらっしゃいませ。何かお探しですか。」
B：「このワンピースの、Sサイズはありますか。」
A：「少々お待ちください。……申し訳ございません、Sサイズは在庫切れです。」
B：「そうですか。では、これをください。カードで払えますか。」
A：「はい。こちらへどうぞ。袋はいりますか。」
B：「いいえ、けっこうです。」
A：「〜円です。ありがとうございました。」
